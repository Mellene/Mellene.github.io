이런 앱이에요

넷플릭스, 유튜브 프리미엄 같은 구독 서비스를 하나씩 등록해두면, 이번 달에 얼마가 나가는지·다음엔 언제 결제되는지를 한 화면에서 볼 수 있어요. 결제일이 다가오면 미리 알림도 보내드려요.

iOS는 다른 앱의 결제 내역을 자동으로 읽어올 방법을 제공하지 않아서, 처음 등록은 직접 입력하는 방식이에요. 대신 자주 쓰는 서비스는 목록에서 고르기만 하면 금액·주기·해지 링크가 자동으로 채워집니다. 한 번 등록해두면 계속 관리돼요.

자주 묻는 질문

구독이 자동으로 불러와지지 않아요.
iOS는 다른 앱이나 웹에서 결제한 구독 정보를 앱이 읽지 못하도록 막아 둡니다. 그래서 PayMonth는 직접 입력하는 방식이고, 대신 서비스를 고르면 금액·주기·해지 링크가 자동으로 채워지도록 해 두었습니다.

해지도 대신 해 주나요?
아니요. 해지 페이지를 바로 열어 주고, 해지한 사실을 기록해 둡니다. 실제 해지는 해당 서비스에서 직접 하셔야 합니다.

입력한 구독 정보는 어디에 저장되나요?
이 기기 안에만 저장되며 어디로도 전송되지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

알림이 오지 않아요.
iOS 설정 > 알림 > PayMonth에서 알림이 허용되어 있는지 확인해 주세요. 앱 안 설정 화면에서 알림 시점(D-3 / D-1 / 당일)과 시각도 바꿀 수 있습니다.
